# Reward City — Step 5 (sound) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Every action and the city itself have sound: the coin beam, hits, unlocks, kiosk play, the box, the finale; an empty grey city that comes alive as colour returns; calm music and a celebratory ending.

**Architecture:** Same as Reward River: `src/audio.js` WebAudio engine (one-shots, smoothed loops, music crossfade, compressor, started by the first key/click), `tools/gen-audio.mjs` runs the fal prompts in `tools/prompts/sfx-*.json` / `music_*.json` into `art-src/audio/raw/`, `tools/process-audio.mjs` applies one linear gain per file (oneshot −16, loop −22, music −16 LUFS) and encodes mp3, `tools/sound-board.html` to audition. `main.js` maps game events to sounds; loops follow state (beam, kiosk play, ambience mix by colour around the camera).

**Tech Stack:** `fal-ai/elevenlabs/sound-effects/v2` (~$0.002/s), `elevenlabs/music/v2.5` (~$0.60/min), ffmpeg.

## As built (2026-11-19)

- 12 new sounds + 2 music tracks on fal (step/jump/land reused from Reward River); coin needed 0.5 s (the SFX endpoint's minimum). `tools/process-audio.mjs` loudness-matched all 17 → 1.9 MB.
- music_city: last 3 s crossfaded into the start for a seamless loop (61 s). zsh gotcha: `$X[h]` in an ffmpeg filter string is an array subscript, write `${X}[h]`.
- `main.js`: audio starts on the first key/click (and on start); M mutes; events → coin (throttled 55 ms, pitch varies), jump, land, kiosk, full, deny, empty, unlock + wash, finale + music_end; footsteps every 0.55 m; beam/play loops follow state; city_grey ↔ city_colour mixed by the colour around the camera.
- Playwright video has no audio: `?recordaudio` taps the compressor into a MediaRecorder, the playtest muxes it onto the video (`tools/playtest-video/playtest.mp4`). Playtest also fails on any undecoded sound.
- `tools/sound-board.html` lists every sound.
